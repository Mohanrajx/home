# AxisEdge Technologies Website

Premium, investor-level marketing website for **axisedge.tech** built with Next.js, Tailwind CSS, and TypeScript.

## Brand Guide

- **Positioning:** High-performance digital engineering and modern web technology studio.
- **Tone:** Premium, confident, minimal, trustworthy.
- **Typography:** Inter (body), Space Grotesk (display).
- **Color System:**
  - Deep Navy: `#0B1220`
  - Charcoal: `#030712`
  - Accent Blue: `#1D4ED8`
  - Accent Teal: `#2DD4BF`
  - Soft Light Background: `#F6F8FB`

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run start
```

## Vercel Deployment

1. Push repository to Git provider.
2. Import project in Vercel.
3. Framework preset: **Next.js**.
4. Build command: `npm run build`.
5. Output: managed by Next.js.
6. Connect domain `axisedge.tech` in Vercel dashboard.
